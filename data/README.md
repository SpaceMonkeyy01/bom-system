# data/

Put the source spreadsheets in `data/raw/` (git-ignored) before running the seed scripts:

- `Bill_of_Materials__October-2026_to_Onward_.xlsx` — the live Google Sheet export
- `BOM_Check.xlsx` — sign-type templates, parameters, Odoo/iFlow product lists
- `Categorization.xlsx` — material master categorisation
- `This_Month-Ali_Hassan_View_1.csv` — Airtable orders export

`data/samples/` holds small, committed fixtures used by tests.
